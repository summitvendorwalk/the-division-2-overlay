## 🧩 About

**The Division 2 Overlay Menu** is a curated list of The Division 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, overlay, loot tracker
- **Quality-of-Life Helpers** — inventory manager, config notes, HUD tweaks
- **Research Notes** — mission layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Combat Helpers
- overlay Overlay — visualize nearby enemies and loot
- Loot Tracker — highlight lootable containers and items
- HUD Config — customize on-screen elements
- Damage Numbers — display floating damage for study

### 🎨 Inventory & Cosmetics
- Inventory Manager — sort and filter gear
- Loadout Notes — save and share builds
- Appearance Catalog — browse cosmetics
- Stats Panel — view detailed character stats

### 🏋️ Quality of Life
- Mission Timer — track completion times
- Waypoint Helper — set custom waypoints
- Auto-Loot Notes — configurable pickup rules
- Chat Overlay — improved chat visibility
